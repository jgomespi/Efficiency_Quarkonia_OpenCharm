## Downstream physics contract

The next analysis stage must use year-specific efficiencies. Do not average 2017 and 2018 maps and do not use either year as a proxy for the other.

Nominal analysis configuration:

```text
ANALYSIS_YEARS = ["2017", "2018"]
ALLOW_YEAR_PROXY = False
```

For each physics bin `k`, correction must be performed within each year before combination:

```text
N_fid(k) = sum_y sum_{i in (k,y)} w_i / epsilon_i^(y)
```

The same-year corrected contributions can then be combined to form the 2017+2018 templates / yields used by the profile-likelihood template fit and data-driven extraction.
