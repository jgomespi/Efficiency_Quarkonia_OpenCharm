# 2017+2018 final efficiency diagnostic — 2026-09-04

## Axis-contract diagnosis

The blocked first version of `tools/audit_final_2017_2018.py` was traced to an
overly strict bitwise comparison of ROOT histogram edges.

`tools/diagnose_final_axes_and_sparse_bins.py` showed:

- all physical bin boundaries printed for 2017 and 2018 are the intended ones;
- every 2017 central/error/N_eff axis comparison that failed exact equality
  passes `np.allclose(..., atol=1e-7, rtol=0)`;
- every 2018-vs-2017 central-axis comparison that failed exact equality also
  passes the same `1e-7` tolerance;
- source and final central axes are identical within each year;
- 2017 and 2018 final `eff_asso_pt` are both `1 x 4` on the intended physical
  grid `[25,100] x [4,10,20,30,60]` GeV.

Therefore the cross-year axis failure is a floating-point serialization / axis
metadata precision effect, not a physical binning mismatch. No 2017 ROOT
regeneration is justified by the axis diagnostic itself.

## Refinalization policy

The selected dimuon grid is now fixed for the preliminary 2017+2018 analysis.
The final ROOTs must be rebuilt from the existing differential ROOT files only;
NanoAOD/Coffea production must not be rerun.

`tools/refinalize_2017_2018_common.py` implements the reviewed decision. It:

- preflights all eight 2017/2018 component files before writing anything;
- verifies that the production formulas reproduce the existing source-grid
  `acc_dimu`, `eff_cuts_dimu`, and `eff_trigger` values from raw weighted sums;
- reconstructs those three maps on `[25,30,50,100] x [0,0.9,1.2]`;
- reconstructs `eff_asso_pt` on the already validated
  `[25,100] x [4,10,20,30,60]` grid;
- uses first-order weighted-ratio error propagation for `acc_dimu`;
- uses effective-statistics Clopper-Pearson intervals for the strict efficiencies;
- keeps original fine maps and raw payloads under `diagnostic/`;
- writes and validates all eight candidate final files before replacing any
  existing final ROOT;
- backs up the current final ROOTs immediately before replacement.

After refinalization, `tools/audit_final_2017_2018.py` is the hard final gate. It
now explicitly requires the selected dimuon grid, the association grid, raw-sum
reproducibility, and `N_eff >= 25` for all four rebuilt maps.

## Cross-year central values before refinalization

The already-computed association efficiencies are stable across years: all
four components show only few-percent 2018/2017 changes in `eff_asso_pt`.
The larger variations were concentrated in `acc_*` and particularly
`eff_trigger` for the sparse SPS-bbbar fine bin. Those fine-grid excursions are
not used to justify any ad-hoc correction; the common rebinning is driven only
by the predeclared `N_eff >= 25` statistical criterion.
