# 2017+2018 final efficiency diagnostic — 2026-09-04

## Axis-contract diagnosis

The blocked first version of `tools/audit_final_2017_2018.py` was traced to an
overly strict `np.array_equal` comparison of ROOT histogram edges.

`tools/diagnose_final_axes_and_sparse_bins.py` shows:

- all physical bin boundaries printed for 2017 and 2018 are the intended ones;
- every 2017 central/error/N_eff axis comparison that failed exact equality
  passes `np.allclose(..., atol=1e-7, rtol=0)`;
- every 2018-vs-2017 central-axis comparison that failed exact equality also
  passes the same `1e-7` tolerance;
- source and final central axes are identical within each year;
- 2017 and 2018 final `eff_asso_pt` are both `1 x 4` on the intended physical
  grid `[25,100] x [4,10,20,30,60]` GeV.

Therefore the cross-year axis failure is a floating-point serialization / axis
metadata precision effect, not a physical binning mismatch.  The final audit
was updated to use a documented `1e-7` absolute edge tolerance rather than
bitwise equality.

No 2017 ROOT regeneration is justified by the axis diagnostic.

## Sparse final bins

The same diagnostic exposed the only final bins with `N_eff < 25`.

### 2017 SPS-bbbar

Both are the highest J/psi-pT and forward-rapidity bin, index `(3,1)`, i.e.
`70 < pT(J/psi) < 100 GeV` and `0.9 < |y(J/psi)| < 1.2`:

- `eff_cuts_dimu`: `N_eff = 21.8725`, central `1.0`, err_down `0.08073`;
- `eff_trigger`: `N_eff = 21.8725`, central `0.46467`,
  err_down `0.12411`, err_up `0.12791`.

### 2018 SPS-bbbar

The same `(3,1)` corner is limiting:

- `acc_dimu`: `N_eff = 15`, central `0.85457`, uncertainty about `0.328`;
- `eff_cuts_dimu`: `N_eff = 12.3669`, central `1.0`, err_down `0.13832`;
- `eff_trigger`: `N_eff = 12.3669`, central `0.71694`,
  err_down `0.18239`, err_up `0.13891`.

The association maps remain above the established hard gate after their common
rebinning: the 2018 SPS-bbbar final `eff_asso_pt` minimum is `36.4446`.

## Current interpretation

The sparse bins are statistically real, not a numerical pathology.  They occur
in the same physical high-pT/forward-rapidity corner in both years and explain
the large SPS-bbbar 2018/2017 trigger-ratio excursions.

Do not ignore these bins and do not rerun NanoAOD processing.  Before physics
integration, determine whether a common J/psi-pT rebinning can bring the dimuon
maps above `N_eff >= 25` while retaining the existing rapidity bins.

The read-only scan is:

```bash
python tools/scan_common_dimuon_rebinning.py
```

It tests every contiguous J/psi-pT partition simultaneously across:

- 2017 and 2018;
- DPS-ccbar, DPS-bbbar, SPS-ccbar, SPS-bbbar;
- `acc_dimu`, `eff_cuts_dimu`, `eff_trigger`;
- both current J/psi rapidity bins.

No final ROOT file should be rewritten until the scan result is reviewed.

## Cross-year central values

The already-computed association efficiencies are stable across years: all
four components show only few-percent 2018/2017 changes in `eff_asso_pt`.
The larger variations are concentrated in `acc_*` and particularly
`eff_trigger` for sparse SPS-bbbar bins, consistent with the low effective
statistics identified above.
